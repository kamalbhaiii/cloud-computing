## 1. Species Selection

Identify at least three target animal species for monitoring. Examples include:

- 🐈 Cats
- 🐕 Dogs
- 🐦 Birds
- 🦔 Hedgehogs
- 🐁 Mice
- 🐀 Rats

Ensure the selected classes are distinct in visual features and relevant to your target habitat.


## 2. Data Collection (Kaggle & Pexels)


Instead of collecting data with hardware, use high-quality public image datasets.

### 📦 Sources:

- 🧠 Kaggle Datasets  
  - Visit https://www.kaggle.com/datasets and search for species-specific datasets (e.g., “cat and dog dataset”, “bird detection”)
  - Download relevant image datasets as .zip files

- 📸 Pexels API / Website  
  - Visit https://www.pexels.com/search/cat/ (replace “cat” with your species)
  - You can use the Pexels API to download copyright-free, labeled images:
    - https://www.pexels.com/api/

Organize the collected data into directories by class:

📁 dataset/  
├── cat/  
├── dog/  
└── bird/

> Note: Ensure all images are clear, high-resolution, and representative of real-world conditions.



## 3. Image Annotation

1.	Image Annotation & Labeling: Label images for object detection, classification, and segmentation with a user-friendly interface.

2.	Dataset Preprocessing & Augmentation: improve model performance with built-in tools like rotation, flipping, noise, blur, and more.

3.	Model Training (AutoML): Train computer vision models without code using Roboflow Train, or export datasets to use with YOLO, TensorFlow, etc.

4.	Model evaluation & Metrics: Get performance insights through precision, recall, mAP, and visualize model results easily.

5.	Deployment via API & Edge Devices: Deploy trained models to  edge devices like Raspberry Pi or Jetson.

6.	Dataset Versioning & Management: Track changes with version control, manage large datasets efficiently, and collaborate with teams.

7.	Data Insights & Labeling Analytics.

## 4. Dataset Organization

Use Roboflow to split the dataset:

- 70% Training Set
- 20% Validation Set
- 10% Test Set

Roboflow handles augmentation and labeling format conversions automatically.

## 5. Model Training (Using Roboflow)

Choose a suitable model architecture (e.g., YOLOv8) in Roboflow.

Training includes:

- Data preprocessing and augmentation
- Iterative learning with validation feedback
- Metric monitoring (mAP, Precision, Recall)

No local GPU required — training is cloud-hosted.

Step:9 model export:

After completing the training phase, the trained model was exported using Roboflow’s export tools for deployment and inference. The model was exported in the YOLOv8 PyTorch format, optimized for CPU-based inference. Additionally, an optional export format was available via Roboflow Lite, which supports Edge TPU devices such as the Google Coral USB Accelerator.

📦 Export Formats

•	YOLOv8 PyTorch (.pt): Suitable for deployment on systems using Python and PyTorch.

•	TensorFlow Lite (.tflite): Lightweight version for inference on edge devices (optional).

🧾 Exported Assets Provided by Roboflow

•	Model Weights: .pt or .tflite file depending on the selected format.

•	Inference Script: A ready-to-use Python script for running the model on new images or video streams.

•	Class Names & Label Map: Files mapping class indices to human-readable labels, essential for interpreting predictions.

This export process simplifies integration into applications, allowing for flexible deployment across a range of platforms—from local machines to embedded edge devices.
