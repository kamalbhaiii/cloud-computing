The software stack is designed to provide a robust, scalable, and efficient wildlife monitoring solution, leveraging modern frameworks, machine learning libraries, and containerized deployment on Raspberry Pi devices.

1. Operating Systems:

* Sensor Node (Raspberry Pi 5)

  Raspberry Pi OS Desktop (64-bit): Debian-based OS optimized for Raspberry Pi hardware, providing stable support for camera modules and peripheral 
  drivers.

* Kubernetes Cluster Nodes (Master- Raspberry pi 4 & Workers - Raspberry Pi 3):

  Ubuntu 22.04 LTS (64-bit): Long Term Support version offering robustness, security updates, and wide community support for Kubernetes and containerized 
  environments.

2. Edge Computing & Object Detection (Sensor Node):

* RoboFlow: For training and running lightweight object detection models optimized for edge inference on Raspberry Pi OS.

* YOLO (You Only Look Once): Real-time object detection framework (YOLOv8), adapted for Raspberry Pi OS and optimized for Coral USB 
  Accelerator.

* Google Coral USB Accelerator: Provides Edge TPU acceleration for TensorFlow Lite models to boost inference speed on the sensor node.

* OpenCV: For handling camera input, image pre-processing, and post-processing on the sensor node.

3. Backend & Cluster (Ubuntu 22.04 LTS Nodes):

* K3s (Lightweight Kubernetes Distribution): Runs on Ubuntu 22.04 to orchestrate backend, frontend, storage, and messaging services across the Raspberry 
  Pi 3 cluster.

* Containers: Container runtime for deploying microservices in the Kubernetes cluster.

* JavaScript(ExpressJS): REST API development framework for backend services that manage sensor data ingestion, node management, and event logging.

* Database (PostgreSQL): To store the timestamps and unique id, path for detected images.

* Object Storage: Minio deployed as distributed storage compatible with S3 API for storing images, logs, and metadata.

4. Frontend (Ubuntu 22.04 LTS Nodes):

* React.js: Frontend framework for creating the web dashboard presenting event logs, images, timestamps, and an interactive map.

* Docker containers: The frontend is containerized and deployed on the Kubernetes cluster.

5. Notifications:

 * Telegram Bot API: Used to send real-time notifications about detected wildlife events to users.

6. Development & DevOps Tools:

* Git & GitHub: Source control and collaboration.

* K3S: Command-line Kubernetes tool for cluster management on Ubuntu nodes.

* Visual Studio Code: Recommended IDE with plugins for Python, Docker, Kubernetes.
