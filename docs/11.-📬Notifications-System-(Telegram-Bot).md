**Telegram Bot API integration:**

Step-1: Use the @BotFather bot in Telegram application to register bot and receive its authentication token.

Step-2: Get the Telegram Chat IDs from the people whom you want to share the notification with.

Step-3: User the /sendPhoto api of Telegram to send the Photo or use /sendMessage api to send just an text message.

**Event trigger conditions:**

Condition-1: If the sensor-node captures the wildlife detection then the server triggers the telegramService to send the image and the caption.

Condition-2: If the github action pipeline detects the changes in frontend or server or k3s directory of the repository then it triggers the notification.

**Sample message format:**

Wildlife Detection Notification:  with caption Detected: <category>
