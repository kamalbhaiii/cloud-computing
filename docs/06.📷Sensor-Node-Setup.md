This section covers the complete configuration of the sensor node using Raspberry Pi 4, camera module, and Roboflow for edge inference.


## 1. Raspberry Pi OS Installation

- Device: Raspberry Pi 4  
- Operating System: Raspberry Pi OS (64-bit) – Bullseye

Steps:

- Use the [Raspberry Pi Imager](https://www.raspberrypi.com/software/) to flash Raspberry Pi OS (Bullseye 64-bit) onto a 32GB microSD card.
- After flashing, boot the Pi and complete the initial setup:
  - Set up Wi-Fi or Ethernet
  - Configure locale and keyboard layout
  - Enable SSH (optional)
  - Update system packages



## 2. Camera Module Setup

- Connect the Raspberry Pi Camera Module v2 (8MP) to the CSI port on the Raspberry Pi.
- Enable the camera module using:
  sudo raspi-config
→ Interface Options → Camera → Enable

- Reboot the Raspberry Pi to apply changes.
- Verify camera functionality using OpenCV or CLI utilities.



## 3. Model Deployment on Edge (Roboflow SDK)

- Use the Roboflow Python SDK to deploy object detection models on the sensor node.
- Export trained models in YOLOv8, or Edge TPU-compatible formats.
- Use the SDK to load the model and perform inference on captured images.
- Models are capable of detecting species such as cats, dogs, birds, etc.



## 4. Edge Detection Process and Inference Loop

- Images are captured either periodically or upon a trigger (e.g., motion detection).
- Each image is processed by the Roboflow model.
- If a valid detection is found:
- Save the image locally or upload it to an object storage system (MinIO).
- Send detection metadata (species, confidence, timestamp, and location) via REST API to the backend server.



## 5. Performance Optimization (Coral USB Accelerator)

- For improved performance, a Google Coral USB Accelerator can be used with the Raspberry Pi.
- Useful when using TensorFlow Lite models compiled for Edge TPU.
- Installation involves:
- Adding Coral's APT repository
- Installing Edge TPU runtime and Python bindings
- Provides significantly faster inference and reduced CPU usage.



> Note: Ensure that USB 3.0 ports on the Raspberry Pi 4 are used for connecting the Coral device for maximum performance.
