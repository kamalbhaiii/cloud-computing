This section covers the complete configuration of the sensor node using Raspberry Pi 4, camera module, and PyCoral for edge inference.


## 1. Raspberry Pi OS Installation

- Device: Raspberry Pi 4  
- Operating System: Raspberry Pi OS (64-bit) – Desktop(bookworm)

Steps:

- Use the [Raspberry Pi Imager](https://www.raspberrypi.com/software/) to flash Raspberry Pi OS (Desktop 64-bit) onto a 32GB microSD card.
- After flashing, boot the Pi and complete the initial setup:
  - Set up Wi-Fi or Ethernet
  - Configure locale and keyboard layout
  - Enable SSH (optional)
  - Update system packages



## 2. Camera Module Setup

- Connect the Camera Modul to the CSI port on the Raspberry Pi.
- Enable the camera module using:
  sudo raspi-config
→ Interface Options → Camera → Enable

- Reboot the Raspberry Pi to apply changes.
- Verify camera functionality using OpenCV or CLI utilities.



## 3. Model Deployment on Edge (Roboflow SDK)

- Use the Roboflow Python SDK to deploy object detection models on the sensor node.
- Export trained models in YOLOv8, or Edge TPU-compatible formats.
- Use the PyCoral SDK to load the model and perform inference on captured images.
- Models are capable of detecting species such as cats, dogs, birds, and humans etc.



## 4. Edge Detection Process and Inference Loop

- Images are captured either periodically(e.g., motion detection).
- Each image is processed by the model.
- If a valid detection is found:
  - Send detection metadata (category, timestamp, and image-buffer) via REST API to the backend server.



## 5. Performance Optimization (Coral USB Accelerator)

- For improved performance, a Google Coral USB Accelerator can be used with the Raspberry Pi.
- Useful when using TensorFlow Lite models compiled for Edge TPU.
- Installation involves:
- Adding Coral's APT repository
- Installing PyCoral runtime and Python bindings
- Provides significantly faster inference and reduced CPU usage.



> Note: Ensure that USB 3.0 ports on the Raspberry Pi 4 are used for connecting the Coral device for maximum performance.

## 6. Setup

  A. System Update

    `sudo apt update && sudo apt upgrade -y`

 B. Install Python & Virtual Environment

    `sudo apt install python3-pip python3-venv -y`

 C. Install OpenCV

    `sudo apt install libatlas-base-dev libjpeg-dev libqtgui4 libqt4-test -y`
    `pip3 install opencv-python`

 D. Install Roboflow Python SDK

    `pip3 install roboflow`

 E. Download and Use Roboflow Model

    `Sign in at https://app.roboflow.com`

 After training your model, go to the Deploy tab

 Select YOLOv5 export

 Use the following Python snippet to load and run inference on your edge device:

 `from roboflow import Roboflow`
 `rf = Roboflow(api_key="your_api_key")`
 `project = rf.workspace("your_workspace").project("your_project")`
 `model = project.version("x").model`
 `prediction = model.predict("your_image.jpg").json()`

 F. Coral USB Accelerator (Optional)

 If your Roboflow model is exported to TensorFlow Lite and Edge TPU format:

  `echo "deb https://packages.cloud.google.com/apt coral-edgetpu-stable main" | sudo tee /etc/apt/sources.list.d/coral-edgetpu.list`
  `curl https://packages.cloud.google.com/apt/doc/apt-key.gpg | sudo apt-key add -`
  `sudo apt update`
  `sudo apt install libedgetpu1-std python3-edgetpu -y`

 G. Camera Enablement

    `sudo raspi-config → Interface Options → Enable Camera`
    `Reboot the Pi`
