**APIs provided (REST endpoints)**

**POST**:/images [uploads the image to backend]
Parameters required:(request body:multipart/form-data]
category:[either daog,cat or bird]
image:image file

**GET**:/images [gets the image to backend]


**PUT**:/images/{name} [updates the image to backend]
Parameters required:(request body:application/json]
category:[either daog,cat or bird]


**DELETE**:/images/{name} [deletes the image from backend]


**Tech-Stack:**

* Framework used: ExpressJS
* Database used: PostgreSQL
* Bucket Used: MinIO
* Architecture used: RESTfull API's with MVC architecture

**Secure Backend with TLS**

Step-1: Create TLS Certificate (Master-node)

`openssl req -x509 -nodes -days 365 -newkey rsa:2048  -keyout tls.key -out tls.crt -subj "/CN=frontend.local/O=local"`

Step-2: Create TLS Secret:

`kubectl create secret tls <tls-name>-tls --key tls.key --cert tls.crt -n default`
