1. Sensor node captures image via Camera

2. Runs inference using pyCoral SDK

3. If detection found:

     * Event data (category, timestamp, image-buffer) sent via REST

4. REST delivers data to Backend API

5. Backend:

    * Saves image to object storage

    * Logs metadata to DB

    * Triggers Telegram alert

6. Frontend fetches data from backend REST API for visualization

    🔐 Security & Resilience

       * Implement retry logic on sensor node in case of network failure

       * Set up k3s with Traefik ingress for secure frontend access

   📦 Deployment Outline

      * Sensor node setup with Python scripts and systemd service

      * Cluster setup with Docker + k3s on Ubuntu

7. Kubernetes YAML/Helm for:

* Server
* MinIO
* Frontend
* Prometheus
* Grafana
* PostgreSQL
* frontend-ingress
* Server-ingress
* Grafana-ingress
