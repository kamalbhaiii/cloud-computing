This project is built using a distributed hardware architecture that includes edge computing nodes (Raspberry Pi-based sensor units), a centralized Kubernetes cluster (for backend/frontend deployment and storage), and supporting peripherals. The hardware is designed to be portable, scalable, and suitable for field deployment in outdoor environments.

🖼️ 2. System Layout:

The hardware system is split into two major components:

A. Sensor Node(s):

1. Raspberry Pi4(Primary)
2. Camera Module connected 
3. Google Coral USB Accelerator connected via USB 3.0
4. Runs object detection locally using YOLO/Roboflow
5. Sends detection events (REST) to backend

B. Kubernetes Cluster:

5x Raspberry Pi 3 Boards and 1x Raspberry pi 4 form a k3s-based HA Kubernetes Cluster.

Deployed components:

1. Backend API services (ExpressJS)
2. Frontend (Reactjs)
3. Object storage (MinIO with S3 API)
4. Data Storage(PostgreSQL)
5. Monitoring(Prometheus,Grafana,Helm charts)

Power and network managed via Anker power hub and Ethernet switch.

🔗 3. Connectivity & Networking:

1. All devices are interconnected via the Gigabit Ethernet switch.
2. Using laptop as a ISP.
3. Static IP configuration using netstat.
4. Sensor nodes and cluster nodes communicate over LAN using REST.
