The Edge Computing Wildlife Monitoring System is a semester-long collaborative project focused on developing a distributed, intelligent wildlife detection solution using edge computing and modern cloud-native technologies. Designed for remote deployment, the system utilizes Raspberry Pi single-board computers equipped with camera module to automatically detect and identify animal species—such as cats, birds, dogs and humans —using object detection models like YOLO and Roboflow.

The sensor node operates independently, performing real-time inference on captured images and transmitting detection data to a central backend system. This backend, deployed on a high-availability Kubernetes cluster of Raspberry Pi 3 devices, handles image storage (via MinIO), data storage (via PostgreSQL), monitoring and system orchestration. A Reactjs-based frontend displays visual insights including, proof images, and log history. Communication between components is facilitated through REST APIs protocols and ClusterIP services.

In addition to monitoring capabilities, the system includes a Telegram bot for real-time notifications upon wildlife detection. This edge-based approach reduces bandwidth usage, supports scalability, and allows for responsive wildlife event tracking. The project aims to explore real-world applications of AI, IoT, and distributed systems while tackling challenges related to performance, reliability, and integration across diverse hardware and software components.
