**APIs provided (REST endpoints)**

**POST**:/images [uploads the image to backend]
Parameters required:(request body:multipart/form-data]
category:[either Dog, Cat or Bird]
image:image file

**GET**:/images [gets the image to backend]


**PUT**:/images/ [updates the image to backend]
Parameters required:(request body:application/json]
category:[either Dog, Cat or Bird]


**DELETE**:/images/{name} [deletes the image from backend]


**Tech-Stack:**

* Framework used: ExpressJS
* Database used: PostgreSQL
* Bucket Used: MinIO
* Architecture used: RESTfull API's with MVC architecture
