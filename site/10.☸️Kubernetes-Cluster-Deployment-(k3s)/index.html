    K3s Deployment

    RPi initial Setup steps:

    Step-1: Flash the SD card with Ubuntu Server LTS or Raspberry Pi OS (Bookworm)

    Step-2: Set the username: and password:

    Step-3: Login into Raspberry Machines using: ssh @

    Step-4: After login, run in terminal sudo apt update && sudo apt upgrade -y

    Step-5: Run in terminal, sudo nano /boot/firmware/cmdline.txt

    Step-6: Add at the end, cgroup_enable=1 cgroup_memory=1, save the file.

    Step-7: Run in the terminal, sudo reboot

    Step-8: Continue the k3s configuration.

    Installation of k3s:

    1) Master Node:

    step 1: curl -sfL https://get.k3s.io | sh -

    step 2: sudo cat /var/lib/rancher/k3s/server/node-token [Copy the output of this command]

    step 3: sudo kubectl label node <master-node-name> node-role.kubernetes.io/worker=master

    2) Worker Nodes:

    step 1: curl -sfL https://get.k3s.io | K3S_URL=https://<master-node-ip>:6443 K3S_TOKEN=<node-token> sh -

    step 2: sudo kubectl label node <worker-node-name> node-role.kubernetes.io/worker=worker

    Low Level Architecture

    Helm or manual YAML deployments: Helm is required only on master-node for Prometheus and Grafana Installation:

    To install Helm-charts:

    $ curl -fsSL -o get_helm.sh https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3

    $ chmod 700 get_helm.sh

    $ /get_helm.sh

    To install Prometheus and Grafana:

    $ helm repo add prometheus-community https://prometheus-community.github.io/helm-charts

    Apply config files of the Prometheus (From Repo):

    $ helm upgrade prometheus prometheus-community/prometheus -f ./config/prometheus-values.yaml
