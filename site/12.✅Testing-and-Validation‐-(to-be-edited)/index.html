    Testing & Validation

    📦 1. Hardware Testing

    Test Case Objective Status Notes
    Power supply test for each Raspberry Pi Ensure all devices boot and run reliably x
    Camera Module test Confirm image capture and video stream works x Use raspistill / libcamera
    Coral USB Accelerator test Verify inference acceleration is working x Use Coral test scripts
    Ethernet connectivity test Check switch and cables x Use ping and iperf
    SD card health test Check read/write speed and stability x Use f3write/f3read

    💻 2. Software Setup Testing

    Test Case Objective Status Notes
    OS boot & SSH access Confirm OS is configured headlessly x
    Docker installation Ensure containerization works x
    k3s cluster formation Master + worker node setup x Use kubectl get nodes
    Pod deployment test Deploy a sample pod successfully x Nginx test pod
    Object detection software test Verify YOLO detection script runs x Try sample input

    📷 3. Detection Pipeline Testing

    Test Case Objective Status Notes
    Image + metadata generation Test detection + metadata creation x Include timestamp, species
    Image compression Check if image is compressed effectively ☐ Check size and quality
    Script auto-run Ensure script executes on boot or trigger ☐ Use systemd or cron

    📡 4. Communication Testing

    Test Case Objective Status Notes
    Image transfer from sensor node to master node Validate reliable file send x Use REST
    Metadata transfer Confirm metadata JSON format + delivery x
    Internal service communication (API endpoints) Test backend REST APIs topics x Use Postman

    🗃️ 5. Storage & Database Testing

    Test Case Objective Status Notes
    MinIO upload test Save image and check access via S3 API x Use MinIO client
    PostgreSQL metadata entry Insert & retrieve metadata records x Use psql or pgAdmin
    Data integrity Ensure no corruption during transfer x Add hash validation

    🧪 6. Backend Testing

    Test Case Objective Status Notes
    Image + metadata ingestion Validate full ingestion pipeline x Unit + integration
    Trigger logic for Telegram Ensure correct events trigger alerts x
    API documentation validation Swagger/OpenAPI working and accessible x

    🖥️ 7. Frontend Testing

    Test Case Objective Status Notes
    Frontend deployment in k3s Check container runs and UI loads x
    Log display functionality Logs are readable and accurate x
    Image viewer and metadata info User can see image + timestamp/species x
    API data sync UI reflects latest data from backend x

    📲 8. Telegram Bot Notification

    Test Case Objective Status Notes
    Telegram bot registration & token Confirm bot is online x
    Message trigger test Trigger from sample metadata event x Include image preview
    Rate limiting Prevent spam in group or chat ☐
    Downlink test (bot commands) Optional bot commands from Telegram ☐ e.g. /status or /last_event

    🛠️ 9. System Resilience & Edge Case Testing

    Test Case Objective Status Notes
    Power loss test Simulate power cut and recovery x
    Network loss test Handle delayed or failed uploads x Queue mechanism
    Node failure recovery One node goes down; system continues x Kubernetes HA validation
    Storage full test Check behavior when MinIO is full ☐ Warning + notification?

    📈 10. Performance Testing

    Test Case Objective Status Notes
    Detection latency Time from image capture to classification x Coral vs no Coral
    Transfer latency Time from detection to data visible in frontend x
    Cluster performance Resource usage during peak load x Use htop, kubectl top
